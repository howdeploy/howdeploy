# Icon sources

The profile uses local copies so its rendering does not depend on third-party CDNs.

- Codex provider mark and OpenClaw: [`openclaw/openclaw`](https://github.com/openclaw/openclaw)
- Kimi CLI: [`MoonshotAI/kimi-code`](https://github.com/MoonshotAI/kimi-code)
- Hermes: [`NousResearch/hermes-agent`](https://github.com/NousResearch/hermes-agent)
- Claude, Gemini, opencode, Linux, Telegram, YouTube, and X: [Simple Icons](https://simpleicons.org/)
- Flipper Zero: [Flipper Devices GitHub organization](https://github.com/flipperdevices)
- Generic creative and website symbols: [Lucide](https://lucide.dev/)

Brand names and marks belong to their respective owners. These assets identify tools used by the profile owner and do not imply endorsement.
